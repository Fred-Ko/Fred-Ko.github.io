# Astro 이전 검증 기록

2026년 11월 12일의 이전 검증을 기록하며, 11월 13일 정리 내용을 덧붙인다. 작업 브랜치는 `feat/astro-design-system`, 작업 위치는 `Fred-Ko.github.io-astro`다. 운영 전환 전 로컬 검토본이며, 원본 `master`의 운영 사이트는 유지되어 있다.

원본 대조 후 요청 없는 변경을 되돌린 최종 기준은 [요청 범위 검토](CHANGE_AUDIT.md)에 있습니다. 이전 과정에서 추가했던 자동 연재·이전/다음·실제 글 코드 접기는 적용하지 않습니다.

현재 상태·폴더·일반 발행 검사는 [작업 인계](../../HANDOFF.md)와 [콘텐츠 안내](../CONTENT.md)를 따른다. 아래 글 수와 브라우저 시험 수는 해당 검토 시점의 결과다.

## 구현 결과

- Jekyll 런타임·Ruby 의존성·테마·구식 프런트엔드 빌드 도구를 제거하고 Astro 프로젝트를 루트로 이전했다.
- 원고 28개와 기존 UUID·nanoId·공개 URL을 보존했다. 삭제 글 3개는 제외했다.
- 실제 글 상세, 20개씩 홈 페이지네이션, 기존 `/page2/`, 태그·카테고리 목록과 개별 페이지, 보관함·소개·404를 구현했다.
- 본문 폭·폰트·테마를 디자인 시스템에 맞추고 모바일 메뉴, 목차, 이미지 확대, 맨 위 이동, 코드 복사와 본문 검색을 연결했다.
- 조회수·익명 좋아요·GitHub 세션·댓글 작성·수정·삭제·로그아웃 화면을 기존 Worker API에 연결했다. Worker 코드와 운영 D1은 변경하지 않았다.
- 읽기 시간, Git 기반 수정일, 글별 1200×630 OG 이미지, canonical·JSON-LD·작성일·수정일 메타데이터, Atom 피드(`/feed.xml`), 사이트맵·robots·GA를 복원했다.
- 초록색 곰 아이콘·웹 앱 매니페스트·CNAME을 보존했다. 기존 `/sw.min.js`는 이전 테마 캐시를 정리하며 새 오프라인 캐시는 생성하지 않는다.
- GitHub Pages 워크플로는 Node 24에서 타입·테스트·빌드·URL 호환성을 검사하고 `dist/`를 배포한다. 일반 브랜치와 PR에서는 검증만 수행한다.

Chromium에서는 실제 문서 간 View Transition 이벤트를 확인했다. Firefox·WebKit에서도 페이지 이동·테마 유지·레이아웃과 기능이 정상 동작함을 확인했다. Playwright WebKit 검증은 Safari 엔진 계열의 자동 시험이며, 실제 iPhone이나 Safari 앱에서 수동 시험했다고 주장하지 않는다.

## 인증 검증의 범위

- 통계 조회·좋아요 추가/취소·조회수 30분 중복 방지·익명 댓글 작성 차단은 실제 로컬 Worker와 로컬 D1로 확인했다.
- 로그인된 댓글 화면은 가상 API 세션으로 작성·수정·삭제·로그아웃을 시험했다.
- 실제 GitHub 계정 승인은 수행하지 않았다. 기존 운영 OAuth 시작 경로가 정상 302를 반환하는 것은 확인했다. 운영 전환 후 계정 승인을 포함한 로그인을 최종 확인할 수 있다.
- 로컬 미리보기에서 실계정 로그인을 하려면 별도의 로컬 OAuth 앱 자격 증명이 필요하다. 이를 운영 자격 증명으로 임의 대체하지 않았다.

## 확인과 배포

로컬 미리보기는 `http://127.0.0.1:4400/`이다. 빌드 결과를 그대로 제공하고 API는 격리한 로컬 Worker `8788`로 전달한다. 예전 시험용 임시 사이트는 이 주소에서 종료했다.

원본 저장소는 그대로 유지한다. 사용자가 로컬 검토를 마친 후 이 브랜치를 운영 브랜치에 병합·푸시하면 GitHub Pages 워크플로가 Astro를 배포한다. 실제 배포와 원격 병합은 이번 완료 작업에 포함하지 않았다.

## 검증 명령

```bash
npm run check:types
npm test
npm run build
npm run check:site
npm run test:browser
```

브라우저 시험 전 로컬 API를 실행하는 명령과 설치 방법은 루트 README를 참고한다. `test-results/`와 Playwright 브라우저 캐시 등 시험 결과물은 커밋하지 않는다.

현재 Astro 원고는 `src/content/posts/`다. 일회성 이전 검사와 일반 발행 검사를 분리했다. 기존 발행 도구가 쓰는 `블로그/`·`assets/img/` 입력의 호환 연결과 실계정 로컬 OAuth 검증은 아직 남아 있다.

## 파일 정리 후 검사 구분

일반 CI는 현재 원고를 기준으로 추가·수정·비공개·MDX·이미지 링크를 검증한다. 28개 고정과 원문 해시는 강제하지 않는다. 기존 URL 117개와 원래 화면을 엄격히 대조하는 `npm run check:baseline`, 원고 변환을 대조하는 `npm run test:migration`은 명시적으로 별도 실행한다. 스냅샷은 `docs/migration/`, 도구는 `scripts/migration/`, 시험은 `tests/migration/`에 있다.
